## Classes in TypeScript

TypeScript adds static typing to JavaScript's class syntax, making object-oriented code safer and more expressive.

### Defining a class

```ts
class Animal {
  name: string;

  constructor(name: string) {
    this.name = name;
  }

  speak(): string {
    return `${this.name} makes a sound`;
  }
}

const dog = new Animal('Rex');
console.log(dog.speak()); // "Rex makes a sound"
```

### Access modifiers

- `public` (default) — accessible anywhere
- `private` — only inside the class body
- `protected` — inside the class and subclasses

```ts
class BankAccount {
  private balance: number;

  constructor(initial: number) {
    this.balance = initial;
  }

  deposit(amount: number): void {
    this.balance += amount;
  }

  getBalance(): number {
    return this.balance;
  }
}
```

### Shorthand constructor params

TypeScript lets you declare and assign properties in one line:

```ts
class Point {
  constructor(public x: number, public y: number) {}
}
const p = new Point(3, 4);
```
